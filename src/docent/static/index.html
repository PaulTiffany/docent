01

Run locally

python -m venv .venv
pip install -e ".[dev]"
docent-serve

Open http://localhost:7860. Deterministic corpus mode is the offline default. Configure an OpenAI-compatible provider for live inference.

02

Run with Docker

docker build -t docent .
docker run --rm -p 7860:7860 docent

The unprivileged container exposes /health on port 7860.

03

Pages + Space

GitHub Pages serves this static client. A Hugging Face Docker Space serves the API. The reference deployment uses OpenRouter through the generic OpenAI-compatible provider; the browser never calls OpenRouter directly. Set the Pages public API URL to the Space URL.

04

Author another docent

Replace the typed public corpus and behavior contract, validate both, then deploy the same gateway and client. Provider credentials remain server-side.
