01

Run locally

python -m venv .venv
pip install -e ".[dev]"
docent-serve

Open http://localhost:7860. Deterministic corpus mode is the offline default and needs no model credential.

02

Run with Docker

docker build -t docent .
docker run --rm -p 7860:7860 docent

The unprivileged container exposes /health on port 7860 and serves the same checked reference collection.

03

Pages + Space

GitHub Pages serves this static client. The reference Hugging Face Docker Space serves the bounded API in deterministic mode. The browser receives only the public Docent API URL.

04

Mediated inference later

Docent keeps evidence authorization and citations. A future AlphaClaw runtime can sit behind the provider boundary without changing the source contract or putting inference credentials in this client.
