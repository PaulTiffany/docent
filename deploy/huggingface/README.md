This Docker Space runs the generic Docent reference implementation. Mock mode is deterministic and requires no model credential. The project state is authored in machine-readable manifests; humans, not the software, select development pathways.

See the [canonical GitHub repository](https://github.com/PaulTiffany/docent) for source, tests, deployment instructions, and scope boundaries.
